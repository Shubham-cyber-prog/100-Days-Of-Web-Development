# 📋 Project Management Board

## 📌 Overview

The **Project Management Board** is a simple task management web application that helps users organize and track tasks across different stages of work.
It uses a **Kanban-style layout** with columns representing task progress such as **To-Do, Doing, and Done**.

This project demonstrates how to build an interactive task board using **HTML, CSS, and JavaScript**, including task creation, filtering, and movement between columns.

---

## 🚀 Features

### ➕ Add Tasks

Users can add new tasks using the input field and **Add Task** button.

### 📊 Task Columns

Tasks are organized into three workflow stages:

* **To-Do** – Tasks that need to be started
* **Doing** – Tasks currently in progress
* **Done** – Completed tasks

### 🔄 Move Tasks

Tasks can be moved between columns using action buttons to update their progress.

### 🔍 Task Filtering

Users can filter tasks using the following options:

* **All** – Displays all tasks
* **Pending** – Shows tasks not yet completed
* **Completed** – Shows completed tasks

### 🎨 Styled Buttons

Buttons have been styled with:

* Modern UI design
* Rounded borders
* Hover effects
* Smooth transitions

This improves the overall appearance and consistency of the interface.

## ⚙️ How It Works

1. The user enters a task in the input field.
2. Clicking **Add Task** creates a new task in the **To-Do** column.
3. Tasks can be moved to **Doing** or **Done** as progress is made.
4. Users can filter tasks using the **All / Pending / Completed** buttons.
