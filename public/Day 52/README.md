# 📋 TaskBoard – Task Management System

**TaskBoard** is a simple and interactive **Task Management Board** built using **HTML, CSS, and JavaScript**.
It helps users organize tasks across different workflow stages such as **To Do, In Progress, Review, and Done**, making it easier to track progress and manage work efficiently.

This project was developed as part of **Day 52 – Task Management Board** in the **100 Days Of Web Development ECWoC26 challenge**.

---

# 🚀 Features

### 🏠 Home / Introduction

A simple introduction explaining the purpose of the task management system and how it improves productivity.

---

### 📊 Dashboard

Displays important statistics such as:

* Total Tasks
* Tasks In Progress
* Completed Tasks

This helps users quickly understand the overall progress.

---

### 📌 Task Management Board

The main Kanban-style board contains four workflow columns:

* **To Do**
* **In Progress**
* **Review**
* **Done**

Users can add tasks to any column and organize their work visually.

---

### ✏ Task Editing

Users can modify task titles if needed.

---

### 🗑 Task Deletion

Tasks can be removed easily from the board.

---

### 🔎 Search Tasks

A search section allows users to quickly find tasks by typing keywords.

---

### 💾 LocalStorage Support

All tasks are stored in **LocalStorage**, which means:

* Tasks remain saved after refreshing the page
* No backend is required
