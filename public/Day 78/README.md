# 🎮 Open-Source Learning Games – Day 78

Open-Source Learning Games is a **collection of interactive educational games** built using **HTML, CSS, and JavaScript**.
The platform provides fun and engaging mini-games designed to help users practice **logic, memory, typing, and problem-solving skills**.

This version improves the **user interface, color contrast, and navigation system** to provide a cleaner and more comfortable learning experience.

---

## ✨ Features

### 🎮 Interactive Games

The platform currently includes multiple learning games:

* ➕ **Math Quiz** – Solve random math problems
* 🧠 **Memory Match** – Test memory with matching cards
* 🔤 **Word Scramble** – Unscramble programming-related words
* ❓ **MCQ Quiz** – Answer programming questions
* ⚡ **Reaction Time** – Measure how fast you react
* 🔢 **Number Guess** – Guess a random number
* ⌨ **Typing Speed** – Test typing accuracy and speed

---

### 🏆 Leaderboard System

* Stores **highest scores** using `localStorage`
* Displays top scores for each game
* Updates automatically when a new high score is achieved

---

### 🎨 UI Improvements

* Softer background colors to **reduce eye strain**
* Clean **card-based layout**
* Smooth hover animations
* Balanced spacing and alignment
* Responsive grid layout

---

### 🧭 Navigation System

Added a structured navigation bar with:

* Home
* Games
* Leaderboard
* About
* Contact

Each tab opens its corresponding section without reloading the page.

---

### 🌙 Dark Mode

* Toggle between **light and dark mode**
* Improves accessibility for night usage

---

## 🛠 Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript**
* **Font Awesome Icons**
* **LocalStorage API**

No frameworks or external libraries are required.
