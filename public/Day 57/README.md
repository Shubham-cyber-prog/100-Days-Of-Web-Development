# 🌱 Habit Tracker Dashboard

A **modern Habit Tracker Dashboard** built using **HTML, CSS, and JavaScript** that helps users build positive daily routines by tracking habits, maintaining streaks, and monitoring progress.

This project was developed as part of **Day 57 – Habit Tracker** in the **100 Days Of Web Development ECWoC26 challenge**.

---

# 🚀 Features

### 🏠 Dashboard Home

A clean introduction section explaining the purpose of the Habit Tracker and how it helps users build consistent habits.

---

### 📖 About Section

Provides information about:

* Why habit tracking is important
* How consistency improves productivity and discipline
* Benefits of maintaining daily routines

---

### 🌱 My Habits

The main section where users can:

* Add new habits
* Edit existing habits
* Delete habits
* Mark habits as completed

Each habit also tracks a **daily streak**.

---

### 🔎 Search Habits

A dedicated search section that allows users to:

* Search habits instantly
* Filter habits by name
* View matching habits in real time

---

### 📈 Progress Dashboard

Displays habit statistics such as:

* Total habits
* Completed habits
* Best streak

Includes a **visual progress bar** showing completion percentage.

---

# 💾 Data Storage

The application uses **LocalStorage** to store habit data.

This ensures that:

* Habits remain saved even after refreshing the page
* User progress is maintained across sessions

---

# 🎨 UI Features

* Dashboard-style layout
* Tab navigation between sections
* Card-based interface
* Smooth UI styling
* Clean header and hero section
