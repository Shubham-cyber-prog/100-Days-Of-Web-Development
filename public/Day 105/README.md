# 🧩 Advanced Form Builder – Day 105

Advanced Form Builder is a **drag-and-drop web application** that allows users to visually create forms, preview them, and view submitted responses.

The project is built using **HTML, CSS, and JavaScript** and stores data locally using **LocalStorage**, making it lightweight and easy to use without a backend.

---

# ✨ Features

## 🧱 Drag & Drop Form Builder
Users can build forms by dragging different field types from the sidebar into the builder area.

Supported fields include:

- Text Input
- Email Input
- Number Input
- Textarea
- Radio Group
- Checkbox Group
- Dropdown Select

Each field can be customized with labels and options.

---

## 👀 Form Preview
The preview page allows users to see how the generated form will look to end users.

Features include:

- Real form rendering
- Working input fields
- Form submission handling
- Success confirmation message

---

## 📊 Responses Dashboard
All submitted responses are saved in **LocalStorage** and displayed in a table format.

Features include:

- Dynamic table generation
- Multiple response support
- Checkbox / radio responses displayed correctly
- Clean readable layout

---

## 📄 Example Form
An example form page demonstrates how a finished form may appear in real-world usage.

This page includes:

- Styled input fields
- Form submission behavior
- UI feedback message
