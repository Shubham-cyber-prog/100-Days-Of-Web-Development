# ✈️ SkyJet Flight Booking System

## 📌 Overview

The **SkyJet Flight Booking System** is a simple web application that allows users to search flights, compare prices, select seats, and confirm bookings.
This project demonstrates how a basic airline booking interface can be built using **HTML, CSS, and JavaScript**.

The goal of the project is to create an interactive and user-friendly flight booking experience while practicing frontend development concepts such as dynamic UI updates, DOM manipulation, and responsive design.

---

## 🚀 Features

### 🔍 Flight Search

Users can search for available flights by entering:

* Departure location
* Destination
* Travel date

### 💰 Compare Prices

Different flights are displayed with their prices so users can choose the best option.

### 💺 Seat Selection

After selecting a flight, users can choose their preferred seat from the available seats.

### 🎫 Booking Confirmation

Once a seat is selected, users can confirm their booking and receive a confirmation message.

### 🎨 Modern UI

The project includes:

* A responsive navigation bar
* Intro section explaining the platform
* Feature cards with hover animations
* Clean and modern layout

## 📖 How It Works

1. The user opens the website.
2. The user searches for flights using the search form.
3. The system displays available flights with prices.
4. The user selects a flight.
5. The seat selection interface appears.
6. The user selects a seat and confirms the booking.
7. A confirmation message is displayed.
