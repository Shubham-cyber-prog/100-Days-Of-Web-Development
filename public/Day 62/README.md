# 📊 GitHub Profile Dashboard

A modern **GitHub Profile Analytics Dashboard** built using **HTML, CSS, and JavaScript** that allows users to search GitHub usernames and view detailed profile statistics, repository insights, and language usage visualization.

This project was created as part of **Day 62 – GitHub Profile Stats Dashboard** in the **100 Days Of Web Development ECWoC26** challenge.

---

# 🚀 Features

### 🔎 GitHub User Search

Users can search for any GitHub username.

* Displays matching GitHub users
* Shows profile avatar and username
* Click on a user to load their dashboard

---

### 👤 Profile Overview

The dashboard displays detailed GitHub profile information including:

* Profile picture
* Name / Username
* Bio
* Location
* Direct link to GitHub profile

---

### 📊 GitHub Statistics

Important GitHub metrics are displayed using statistic cards:

* Total Public Repositories
* Followers
* Following
* Public Gists

---

### 📈 Language Statistics Chart

A **Chart.js visualization** shows the distribution of programming languages used in the user's repositories.

This helps understand the user's technology stack at a glance.

---

### 📂 Top Repositories

The dashboard highlights the most popular repositories of the user based on star count.

Repository cards show:

* Repository name
* Description
* Stars ⭐
* Forks 🍴
* Primary language

---

### 🎨 Modern UI Design

The project includes a clean and responsive user interface:

* Card-based layout
* Smooth spacing and alignment
* Responsive design
* Styled statistics dashboard

# ⚙️ How It Works

1. Enter a GitHub username in the search bar.
2. The application uses the **GitHub Search API** to find matching users.
3. Clicking a user loads their profile dashboard.
4. The app fetches repository data and generates statistics.
5. A chart visualizes language usage.
